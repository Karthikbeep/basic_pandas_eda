# 📊 Basic Exploratory Data Analysis

This project is a **basic Exploratory Data Analysis (EDA) exercise** created as part of my Data Analytics learning journey.

The goal of this project is to practice using **Pandas to explore, analyze, and extract insights from a dataset** by answering simple business-related questions.

## 🎯 Objectives

Through this project, I practiced:

- Understanding the structure of a dataset
- Checking data types and data quality
- Identifying missing values
- Performing aggregations using `groupby()`
- Analyzing sales and quantities
- Comparing products and cities
- Calculating averages
- Answering basic business questions using data

## 📌 Dataset

The dataset contains basic retail sales information, including:

- Order ID
- Order Date
- Product
- Category
- City
- Sales
- Quantity

## 🔍 Questions Explored

Some of the questions explored in this analysis include:

- How many rows and columns are in the dataset?
- Are there any missing values?
- Which product generated the highest revenue?
- Which city generated the highest revenue?
- Which product sold the most units?
- Which product performs best in terms of revenue and quantity sold?

## 🛠️ Tools & Libraries

- Python
- Pandas
- Jupyter Notebook

## 💡 Key Insights

The analysis showed that:

- **Laptop** generated the highest revenue.
- **Phone** had the highest quantity sold.
- **Hyderabad** generated the highest total revenue.
  

## 📈 What I Learned

This project helped me understand how EDA can be used to move from **raw data → analysis → business insights**.

It also gave me hands-on practice with Pandas operations that are commonly used in Data Analyst workflows.
